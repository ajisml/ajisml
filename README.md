## 🚀 Featured Project

### 🔧 ScheduleIC (Go)
**ScheduleIC** is a command-line automation tool built with **Go**, designed to run scheduled and on-demand inventory processes.

Key highlights:
- CLI-based execution (`ScheduleIC.exe command -flag`)
- Automated daily & periodic jobs
- Heavy MySQL data processing (large tables, dynamic periods)
- Inventory Control workflows (sales, stock, NKL, NBR, BAP, tagging, reporting)
- Designed for **performance, stability, and unattended execution**
- Suitable for **Task Scheduler / Cron-like environments**

This project reflects my focus on **backend performance**, **data accuracy**, and **operational efficiency**.
